Internship Day 10 Documentation

Day 10 Overview

On Day 10, we explored Firebase and its role in modern application development. We learned how Firebase can be used as a Backend-as-a-Service (BaaS) platform for building scalable web and mobile applications. The session also included project discussions, idea validation, and planning future project implementations using Firebase services.

Introduction to Firebase

Firebase is a cloud-based platform developed by Google that provides backend services for web and mobile applications. It helps developers build applications faster without managing traditional servers.

  • Developed and maintained by Google
  • Backend as a Service (BaaS)
  • Cloud-based infrastructure
  • Real-time data synchronization
  • Easy deployment and scalability

Firebase Services Explored

  • Firebase Authentication: User login and account management.
  • Cloud Firestore: NoSQL cloud database for application data.
  • Firebase Hosting: Fast and secure website deployment.
  • Firebase Storage: File and image storage.
  • Cloud Functions: Backend logic executed on Google's cloud servers.

Project Discussion Session

Firebase Development Workflow

  1. Create a Firebase Project
